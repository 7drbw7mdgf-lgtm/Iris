# Iris 5.2.0 — ChatGPT & LLM Developer & Visualization Guide

Welcome! This archive contains the complete source code and execution contract for **Iris 5.2.0**, an open-source, publication-grade scientific data visualization and statistical analysis platform built with React, TypeScript, and Tauri (Rust).

---

## 1. Quick Architecture Overview

Iris bridges interactive graphical data manipulation (Excel/Prism-like spreadsheet) with reproducible scientific programming (R/ggplot2 and Python matplotlib/seaborn/altair/plotly).

- **Frontend (`src/`)**: React 19 + TypeScript + Vite.
  - `src/App.tsx`: Main application shell, state management, tab routing, graph generation orchestration.
  - `src/components/DataPanel.tsx`: Full-featured Excel-like spreadsheet with live formula bar, 40+ functions (`SUM`, `AVERAGE`, `COUNTIF`, `VLOOKUP`, `IF`, etc.), ribbon toolbar, and coordinate-clamped context menus.
  - `src/components/BottomPanel.tsx`: Code Studio & **ChatGPT Visualization Studio Assistant**. Allows copy/pasting scripts with automatic markdown fence stripping, quick prompts, and prompt scaffolding.
  - `src/components/Inspector.tsx`: Right sidebar controls that adaptively show only relevant configuration shelves based on the selected `GraphType`.
  - `src/app/modals/ChartTypePaletteModal.tsx`: Visual gallery of 50+ publication chart types categorized by analytical purpose.
  - `src/components/SettingsModal.tsx`: Settings, diagnostic tests, R/Python environment configuration, and release info (v5.2.0).
  - `src/rgen/`, `src/pgen/`, `src/plotlyGen/`: Script and preview generators for R (ggplot2), Python (matplotlib/seaborn/plotly/altair), and Plotly previews across all chart types.
  - `src/types.ts`: Core data structures (`Dataset`, `PlotSpec`, `GraphType`, `PaletteName`, `ThemeName`).

- **Backend (`src-tauri/`)**: Rust Tauri application.
  - Native file dialogs, system shell execution, script evaluation, and DMG packaging.

## 2. Iris Script Execution Contracts (for ChatGPT)

When writing or editing visualization scripts for Iris users, adhere to these strict contracts:

### Python (Matplotlib / Seaborn / Plotly / Altair)
1. **Top-Level Variable Contract**:
   - The script must expose exactly one top-level figure object named `fig` (e.g. `fig, ax = plt.subplots(...)` or `fig = px.scatter(...)`).
   - Iris reads `fig` directly to render in the GUI and export publication-ready SVGs/PDFs/PNGs.
2. **Never Call `plt.show()` or `plt.close(fig)`**:
   - Calling `plt.show()` blocks the GUI thread.
   - Calling `plt.close(fig)` destroys the figure before Iris can inspect its artists.
3. **No `if __name__ == '__main__':` Guard**:
   - The script is executed in an embedded Python interpreter session. Do not wrap definitions inside main guards.
4. **Data Access**:
   - Data is passed as a pandas DataFrame named `df` matching the active spreadsheet columns.

### R (ggplot2)
1. **Top-Level Object Contract**:
   - The script must assign the final plot to `p` (e.g., `p <- ggplot(...) + ...`) or evaluate `p` as the last expression.
2. **Libraries**:
   - Common libraries available: `ggplot2`, `dplyr`, `tidyr`, `scales`, `ggpubr`, `viridis`.
3. **Data Access**:
   - Data is available as a data frame named `df`.

## 3. How to Prompt ChatGPT to Edit an Iris Script

In Iris 5.2.0, open the **Code Studio** (`BottomPanel`), click **🤖 ChatGPT**, select a prompt chip (or write a custom instruction), and click **📋 Copy for ChatGPT**.

Example Prompt generated by Iris:
```markdown
# Task: Edit Iris Scientific Studio Visualization
You are an expert scientific visualization assistant editing an Iris script.

## Environment & Contract
- Target language: Python
- Iris execution contract:
  - Expose exactly one top-level figure object named `fig`.
  - Do NOT call `plt.show()` or `plt.close(fig)`.
  - Do NOT wrap in `if __name__ == '__main__':`.
- Available data columns: Day (numeric), CellTiter (numeric), Treatment (string)
- Active chart type: errorBar
- Theme & Palette: nature / npg
- Variables: X=Day, Y=CellTiter, Group=Treatment

## Current Script:
[paste script here]

## Requested Change:
Add statistical significance brackets with Holm-Bonferroni adjusted p-values between Control and Treatment at Day 7 and Day 14.

## Instructions:
1. Return ONLY the complete, revised, and runnable Python code.
2. Maintain all column references and ensure zero syntax errors.
```

Paste ChatGPT's response directly back into Iris using the **📥 Paste from ChatGPT** button. Iris will automatically strip any markdown backticks (` ```python `) and update the plot.

## 4. Building and Running from Source

```bash
# 1. Install dependencies
npm install

# 2. Run developer mode
npm run tauri dev

# 3. Run test suite
npm test

# 4. Check TypeScript types
npx tsc --noEmit

# 5. Build macOS DMG
npm run bundle:dmg
```
